# 模型授权与出处

这个目录里的 `.onnx` 都是第三方训练的权重，跟着仓库一起发。
**Apache-2.0 要求再分发时附带授权和署名**，所以这份文件是必需的，不是可有可无的说明。

选型只有一条硬线：**能商用**。当初 RobustVideoMatting 效果很好，
因为是 GPL-3.0 直接拒掉了；RAW 解码那边拒掉 LibRaw / DNGlab 也是同一条线。

| 文件 | 模型 | 授权 | 上游 |
|---|---|---|---|
| `isnet-general-use.onnx` | IS-Net (DIS) | Apache-2.0 | [xuebinqin/DIS](https://github.com/xuebinqin/DIS) |
| `u2net_human_seg.onnx` | U²-Net 人像分割 | Apache-2.0 | [xuebinqin/U-2-Net](https://github.com/xuebinqin/U-2-Net) |
| `MiDaS-large.onnx`、`MiDaS-small.onnx` | MiDaS 单目深度 | MIT | [isl-org/MiDaS](https://github.com/isl-org/MiDaS) |
| `SCUNet-real.onnx` | SCUNet 盲降噪 | Apache-2.0 | [cszn/SCUNet](https://github.com/cszn/SCUNet) |

`SCUNet-real.onnx` 的来历多一步：权重来自 cszn/SCUNet（Apache-2.0），
ONNX 转换取自 [deepghs/image_restoration](https://huggingface.co/deepghs/image_restoration)（MIT），
本地又用 onnx-simplifier 按固定输入尺寸重新折叠了一遍（见下）。

## 为什么降噪选了 SCUNet

拿项目自己的一帧画面加上已知噪声，在 onnxruntime 上量过 PSNR（512×512 一块，CPU）：

| 噪声 | 噪声图 | SCUNet | NAFNet-SIDD |
|---|---|---|---|
| 高斯白噪 σ=15/255 | 24.66 dB | **35.40 (+10.74)** | 27.88 (+3.22) |
| 高斯白噪 σ=25/255 | 20.34 dB | **33.20 (+12.86)** | 19.43 (**−0.91**) |
| 泊松-高斯（像真实高感） | 25.94 dB | **35.82 (+9.88)** | 28.63 (+2.69) |

NAFNet-SIDD 只在 SIDD 那个噪声量级上管用，σ=25 时**把图弄得更糟**，
而且它是 446MB。同样的活 SCUNet 用 87MB 干得好一个数量级，所以没有收 NAFNet。

> 拿高斯白噪一个人当判据会偏袒在白噪上训练的模型，所以加了一档泊松-高斯——
> 亮处噪声大、暗处有底噪，那才是传感器真实的样子。两档结论一致。

**干净图过一遍是 39.9 dB 而不是 99 dB**：模型总会抹掉一点东西。
所以降噪强度做成了可调的混合比，不是开关。

## 为什么要重新简化一遍

deepghs 那份导出是动态输入尺寸的，`roll` 和窗口注意力被展开成一大堆
`Range` / `Expand` / `ScatterND` / `ConstantOfShape`——6639 个节点，
每次推理都要把这些形状运算重算一遍。128×128 一块在 CPU 上要 8.9 秒，
其中绝大部分是这些跟像素无关的开销。

按固定输入尺寸跑一遍 onnx-simplifier，这些能在编译期折叠掉。
重新生成的办法：

```bash
pip install onnx onnxsim
python - <<'EOF'
import onnx
from onnxsim import simplify
m = onnx.load("SCUNet-PSNR.onnx")          # deepghs/image_restoration
sm, ok = simplify(m, overwrite_input_shapes={"input": [1, 3, 576, 576]})
assert ok
onnx.save(sm, "SCUNet-real.onnx")
EOF
```

**576 = 512 的块 + 两边各 32 的上下文**，也正好是 64 的倍数
（SCUNet 是四次下采样的 UNet，边长必须能被 64 整除）。
换块大小就得重新导一份——`AiDenoiser.Spec.align` 和这里必须对得上。
